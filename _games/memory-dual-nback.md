## Overview

Indicate whether the current position matches the position shown 1 step ago.

## Instructions

A square flashes in a 3x3 grid every 2 seconds. Press "MATCH" if the square is in the exact same position as the previous step; press "DIFFERENT" if it moved.

## Strategy & Pro Tips

Do not think about steps from 2 turns ago. Continuously overwrite your mental snapshot with the newest position.

## Underlying Mechanics

Continuous N-Back working memory protocol for executive function priming.
