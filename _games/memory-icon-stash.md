## Overview

A set of icons is displayed. One icon is quietly removed. Identify what vanished.

## Instructions

Inspect the cluster of 8 symbols. When the screen flashes, 7 symbols return while 1 is missing. Choose the missing symbol from the candidate list below.

## Strategy & Pro Tips

Subvocalize categories (e.g., "Anchor, Key, Sun, Cup...") to create an audio index in your mind.

## Underlying Mechanics

Working memory object permanence and item-inventory verification.
