## Overview

Rapidly alternate between keys A and B (or Left and Right buttons) without double-tapping either.

## Instructions

Alternate hitting button A then B as fast as humanly possible for 10 seconds. Pressing the same button twice in a row incurs an invalid stroke penalty.

## Strategy & Pro Tips

Use index and middle finger like walking legs; establish a fluid reciprocal rocking rhythm.

## Underlying Mechanics

Alternating binary state machine testing inter-digit coordination.
