# ReptileBirds — Official Web Platform

Welcome to **[ReptileBirds](https://reptilebirds.com/)** — a fast, lightweight client-side web platform.

## 🛠️ Development & Build Pipeline

### Installation
```bash
npm install
```

### Local Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
